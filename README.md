# Гравитация иначе

Статический интерактивный самоучитель по модифицированной гравитации на русском языке. Содержит 35 тем с теорией, проверкой знаний и 111 дополнительными вопросами и задачами с разборами, включая адаптации шести задач из задачника Лайтмана и соавторов, пререквизиты по механике, углублённые расчёты, три интерактивных симулятора и список источников. Отдельный раздел «Задачник» содержит 16 адаптаций задач из глав 1–3 сборника Лайтмана и соавторов, с подсказками и пошаговыми решениями. Прогресс курса хранится локально в браузере.

Откройте `index.html` или запустите локальный сервер, например `python3 -m http.server 8000`. Проект подходит для размещения на GitHub Pages и не требует сборки или сервера приложений.

Симуляторы — учебные модели: точечная масса, часы при равномерном движении и плоская FLRW-модель без излучения. Они не являются подгонкой реальных наблюдений. Научные утверждения и их ограничения раскрыты в темах и источниках.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**. После сборки адрес сайта появится в разделе Pages; обычно это `https://projectaaj2025-sys.github.io/gravity/`.

Формулы отображаются локально с помощью KaTeX (лицензия MIT; см. `assets/katex/LICENSE`). Исходные LaTeX-записи вынесенных формул находятся в `math-render.js`.

Дополнение по конспекту С. О. Алексеева: компактификация Калуцы — Клейна, модель ADD, модели RS и слабополевой предел Бранса — Дикке. Уточнены предпосылки и приведены самостоятельные упражнения; использованы доступные лекции 1–3 конспекта. Новые формулы задаются явным LaTeX через `data-tex` и `data-tex-display`.

Для проверки структуры курса и синтаксиса формул без установки пакетов: `node tests/course-integrity.cjs`. Внутритекстовые выражения имеют проверенные явные шаблоны в `inline-equations.js`; сложные формулы новых тем заданы явным LaTeX.
