# Гравитация иначе

Статический интерактивный самоучитель по модифицированной гравитации на русском языке. Содержит 20 тем с теорией и проверкой знаний, углублённый раздел по массивной гравитации, симулятор кривых вращения и список источников. Прогресс хранится локально в браузере.

Откройте `index.html` или запустите локальный сервер, например `python3 -m http.server 8000`. Проект подходит для размещения на GitHub Pages и не требует сборки или сервера приложений.

Симулятор — учебная модель изолированной точечной массы, а не модель реальной галактики. Научные утверждения и их ограничения раскрыты в темах и источниках.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `arena/ce1e8882-gravity` и папку `/ (root)`, затем нажмите **Save**. После сборки адрес сайта появится в разделе Pages; обычно это `https://projectaaj2025-sys.github.io/gravity/`.
